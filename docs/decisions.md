implementation choices made while executing the approved plan, deviations

- **P01 input (M7):** on this session's host, a 1 s real-clock replay showed
  scheduler wake error of p50 ≈ 5.0 ms and p95 ≈ 9.0 ms (n = 50). A scratch probe found
  the same magnitude for every `sleep(until:tolerance:)` tolerance (nil, 0,

  `mach_wait_until` baseline (p50 ≈ 4.0 ms, max ≈ 5.0 ms). The delay is
  host-level, not added by the harness. These numbers come from an agent
  session with unknown load and power state, so they are **not** a P01
