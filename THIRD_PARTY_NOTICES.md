# Third-party notices and license scope

This is an inventory, not legal advice. It records which terms apply to what, so that nobody mistakes
the project license for permission to redistribute someone else's code, models or data.

## What the project MIT License covers

[`LICENSE`](LICENSE) (MIT) applies to files authored for this repository: the Swift and Python
sources, tests, scripts, configs, schemas, documentation, and the synthetic tone/silence fixtures
generated by `scripts/generate_fixtures.py` (`datasets/fixtures/`, `datasets/manifests/synthetic.json`,
`testdata/`).

It does **not** cover:

| Item | Where | Terms |
|---|---|---|
| `patches/speech-swift-3f58a58a-phase1.patch` | committed | A modification of speech-swift source, which is Apache-2.0. The patch is distributed under Apache-2.0 as a changed-files notice for the two files it touches. |
| Swift and Python dependencies | fetched by SwiftPM/pip, not committed | Their own licenses (below) |
| speech-swift source | `vendor/speech-swift/`, git-ignored, created locally | Apache-2.0 |
| Model weights and conversions | never committed; supplied by each user | Original NVIDIA checkpoint terms **and** each conversion repository's terms (below) |
| AMI Meeting Corpus audio and annotations | never committed | AMI corpus terms (below) |
| Historical campaign evidence | root `evidence/`, git-ignored | Not published. Only the curated summaries in `docs/phase1/evidence/` are |

## Data (never committed)

- **AMI Meeting Corpus** (audio and manual annotations 1.6.2), <https://groups.inf.ed.ac.uk/ami/corpus/license.shtml>:
  the corpus is distributed under CC BY 4.0. This repository commits no AMI audio, transcript text or

  under the project MIT License.
